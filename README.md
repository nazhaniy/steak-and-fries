# Steak & Fries

A Grade 12 Calculus & Vectors (MCV4U) learning site: lessons, homework, quizzes and tests on the
product rule, quotient rule, essential derivatives and rates of change. A CIMP project.

Open `index.html`, or visit the GitHub Pages link for this repository.

## How it stores things

This version keeps everything in the browser of the device it runs on. Quiz answers, scores,
teacher marks and any questions added on the Staff page stay on that device. Another phone or
laptop starts fresh with the built-in questions.

## Staff page

Use **Staff sign-in** at the bottom of any page. The first visit on a device asks you to create a
staff password. It is a light lock for demonstrations, not real security.
